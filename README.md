# CS230

The client was The Gaming Room, creator of the game Draw It or Lose It for Android. They wanted it redesigned as a web-based, multi-platform application for desktop and mobile use. The software needed to support multiple users, teams, and sessions with unique names and secure communication.

I organized the software design document clearly and aligned each section with client needs. The document presented technical and business requirements in a simple, structured way.

The design process provided a clear blueprint before coding. It defined how classes, objects, and services would interact and ensured scalability, security, and consistency.

If revised, the recommendations section would include details on performance testing and continuous integration to strengthen deployment readiness.

User needs were implemented through focus on scalability, accessibility, and security. Meeting user needs is essential to create efficient, reliable software.

The design approach was modular and methodical, using object-oriented design, client-server separation, and iterative refinement. Future projects would use structured analysis, UML diagrams, and design patterns for scalability and maintainability.
